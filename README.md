# Real Estate Market Intelligence Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard designed to analyze real estate market dynamics and support investment and development decisions.

## 🎯 Objectives

- Analyze property prices and rental yields
- Track market demand and supply conditions
- Analyze unsold inventory and market activity
- Identify geographical real estate hotspots
- Compare different cities and property types
- Support investment decision-making

## 🛠️ Tools Used

- Power BI
- DAX
- Microsoft Excel / CSV
- Data Visualization
- Data Analysis

## 📈 Dashboard Pages

### 1. Executive Overview
Provides a high-level overview of:
- Property prices
- Price per square foot
- Rental yields
- Demand and supply
- Geographic distribution

### 2. Price & Rental Analysis
Analyzes:
- Property price trends
- Price per square foot
- Monthly rent
- Rental yields
- City and property-type comparisons

### 3. Demand & Supply Analysis
Analyzes:
- Demand trends
- Supply trends
- Units sold
- New listings
- Unsold inventory
- Days on market
- Market pressure

### 4. Geographic Hotspots
Uses geographic visualizations to identify:
- Property hotspots
- Price differences between cities
- Rental yield differences
- Demand and supply patterns

### 5. Investment Intelligence
Provides insights into:
- Rental yield
- Property prices
- Market pressure
- Demand
- Investment attractiveness

## 📊 Dataset

The project uses a synthetic real-estate dataset containing property, pricing, rental, demand, supply, economic and geographic information across multiple Indian cities.

## 📌 Key DAX Measures

- Total Properties
- Average Property Price
- Average Price per Sqft
- Average Rental Yield
- Total Units Sold
- Total New Listings
- Total Unsold Inventory
- Average Demand Index
- Average Supply Index
- Average Days on Market
- Market Pressure
